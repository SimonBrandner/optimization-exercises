# Cvičení z Optimalizace

V tomto repositáři se nachází [řešení domácích
úloh](https://simonbrandner.github.io/optimization-exercises/main.pdf) z
[předmětu Optimalizace](https://cw.fel.cvut.cz/wiki/courses/b0b33opt/start),
který je vyučovaný na FEL ČVUT. Řešení úloh mohou obsahovat chyby (pokud nějaké
najdete, prosím ohlašte je). Tyto materiály prosím využívejte pouze v souladu s
pravidly předmětu.
